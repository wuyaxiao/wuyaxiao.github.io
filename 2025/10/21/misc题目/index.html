图片隐写

PNG 文件隐写与分析技术

组成部分 字节数 描述 魔术数字/标记
文件签名（Magic Number） 8 字节 用于识别文件是有效的PNG格式。 89 50 4E 47 0D 0A 1A 0A (十六进制)
数据块（Chunk） 可变 包含图像数据、元数据、调色板等信息。一个PNG文件由多个数据块组成。 N/A (每个块有自己的类型)

49 45 4E 44 AE 42 60 82 是 PNG IEND块（文件结束标记）

1. 修改宽高（一般是高）
  • 原理： PNG 文件头中的 IHDR 数据块存储了图像的宽度（Width）和高度（Height）。出题者会故意将真实的图片高度改小，使得图片底部的一部分像素数据被隐藏，无法正常显示。
  • 目的： 隐藏的像素区域可能包含 Flag、二维码或重要的线索。
  • 解题关键：
    • 使用十六进制编辑器（Hex Editor）查看 PNG 文件，找到 IHDR 数据块中表示高度的 4 个字节（通常在文件偏移量 20-23 处）。
    • 尝试将高度值改大（例如，改为一个非常大的值，或者通过 CRC 爆破找到真实值）。
    • CRC 校验报错： 这是最大的提示！ 当你修改了高度值后，文件末尾的 CRC 校验码就会失效，图片查看器会报错。你需要重新计算修改后的 IHDR 数据块的 CRC-32 值，并替换文件中的旧值，才能让图片正常显示。
2. LSB（最低有效位隐写）隐写文件或文字或图片
  • 原理： LSB（Least Significant Bit）隐写是利用数字图像中人眼对颜色微小变化不敏感的特性。
    • 对于一个 24 位（真彩色）的像素点，R、G、B 各占 8 位。将每个颜色分量的最低一位（即 LSB）替换成秘密信息的数据位。
    • 由于 LSB 改变只会使颜色值最大变化 1（人眼无法察觉），因此秘密信息被完美地隐藏在视觉上没有变化的图像中。
  • 目的： 隐藏文本（Flag）、压缩文件或其他图片。
  • 解题关键：
    • 使用专业工具（如 zsteg、StegSolve）对 PNG 文件进行分析，让工具自动提取 LSB 中的数据。
3. 两张图片异或 (XOR)

  • 原理： 这是双图盲水印解法的核心操作。它基于以下数学特性：

    $$\text{A} \oplus \text{A} = 0$$

    $$\text{A} \oplus \text{B} \oplus \text{A} = \text{B}$$

  • 目的： 当题目提供两张几乎相同的图片 $I_1$ 和 $I_2$ 时，通常意味着：

    • 双图盲水印： $I_1$ 和 $I_2$ 都嵌入了相同的 Flag ($W$)，但载体有微小差异。XOR 操作可以消除大部分载体背景，突出水印。
    • 隐写差异： $I_1$ 是原始图，而 $I_2$ 只是在某部分像素上做了轻微修改（比如嵌入了 Flag）。XOR 运算会使两个图片不同的区域显示为亮色。

  • 解题关键： 使用 Python 脚本（NumPy/OpenCV/PIL）或 StegSolve 的 Image Combiner -> XOR 功能，对两张图片的像素值进行异或运算，观察得到的差异图。

4. cloacked-pixel
  • 原理： Cloaked Pixel（隐形像素）是一种隐写工具，它利用 PNG 或其他图像格式中肉眼不可见的像素变化来编码数据。它可能与 LSB 类似，但通常涉及到更复杂的颜色通道操纵或压缩特性。
  • 目的： 隐藏 Flag 或秘密文件。
  • 解题关键： 通常需要使用专门的 Cloaked-Pixel 解密工具（如果出题人使用了该工具）或深入分析像素的颜色值，寻找异常的、不符合周围环境的像素点。
5. apng (可以考双图盲水印)
  • APNG (Animated Portable Network Graphics)：
    • 原理： APNG 是 PNG 的扩展格式，支持动画。它由多个**帧（Frame）**组成，类似于 GIF，但支持 PNG 的所有特性（如 24 位颜色和 Alpha 透明度）。
    • 与双图盲水印的关系： 出题人可以将 Flag 隐藏在 APNG 动画的某一个帧中，或者将 $I_1$ 作为第一帧，$I_2$ 作为第二帧。这迫使解题者必须将 APNG 拆解成独立的 PNG 帧文件，然后再对帧文件进行双图异或操作来提取水印。
  • 解题关键： 使用 APNG 拆解工具（如 FFmpeg 或在线工具）将动画拆分为一系列单帧 PNG 文件，然后对这些帧文件进行分析或异或运算。

盲水印

  • java盲水印：提示出题人可能使用 Java 语言编写的盲水印工具或框架（而不是 Python 或 C++）来嵌入水印。那么常规的 Python 工具可能无法直接兼容或提取。解题者可能需要找到对应的 Java 程序或反向工程该程序。
  • watermarkH：如果一张图试了一堆工具都不行，可以考虑一下WaterMarkH
  • bwm双图盲水印：blind-watermark 是一个流行的 Python 库，常用于 CTF 中。只要有无水印的原图和添加了盲水印的图就可以通过blind-watermark提取盲水印
  • 傅里叶变换： 傅里叶变换（Fourier Transform, FT）是图像处理中将图像从空域（像素域）转换到频域（Frequency Domain）的关键技术。基于傅里叶变换或其衍生的离散余弦变换（DCT）、小波变换（DWT）的盲水印算法，通常将水印嵌入到图像的中低频部分，以实现鲁棒性（抵抗压缩、裁剪等攻击）。
    • 解题关键：
      • 需要对图像进行傅里叶变换。
      • 观察变换后的频域图，查找是否有异常的、周期性的结构（这往往是水印的特征）。
      • 尝试对频域的特定区域进行修改或提取，然后进行逆变换返回空域观察结果。

50 4B 01 02：中央目录文件头标识（0x02014b50）

【版本信息区】

  • 14 00：压缩所用PKWare版本（本例为2.0）
  • 14 00：解压所需PKWare最低版本（本例为2.0）

【通用位标记与压缩信息】

  • 00 00：通用位标记（用于加密、数据描述符等）
  • 08 00：压缩方法（08 = DEFLATED）
  • 5A 7E：文件最后修改时间（与本地文件头相同）
  • F7 46：文件最后修改日期（与本地文件头相同）

【校验与尺寸信息】

  • 16 B5 80 14：CRC-32校验值（1480B516）
  • 19 00 00 00：压缩后大小（25字节）
  • 17 00 00 00：未压缩大小（23字节）

【文件名与额外字段信息】

  • 07 00：文件名长度（7字节）
  • 00 00：额外字段长度（0字节）
  • 00 00：文件注释长度（0字节）

【磁盘与文件属性】

  • 00 00：文件开始磁盘号（0 = 本磁盘）
  • 00 00：内部文件属性（通常为0）
  • 20 00 00 00：外部文件属性（操作系统相关，例如存档属性）
  • 00 00 00 00：本地文件头的相对偏移量（重要！指向 50 4B 03 04 的位置）

【可变长度数据区】

  • 6B 65 79 2E 74 78 74：文件名（key.txt 的ASCII码）
